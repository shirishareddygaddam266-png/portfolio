# Azure Data Engineering & ETL

## Overview

Portfolio case study based on Shirisha Gaddam's Data Engineer experience at Merck Pharma (Jun 2023 – Present).

The resume documents work focused on cloud data integration, ETL automation, SQL performance, business intelligence and Azure Data Lake access.

## What I Worked On

- Engineered **20+ Azure Data Factory pipelines** integrating on-premises data into Azure Synapse.
- Improved data reliability and processing speed by **30%**.
- Optimized complex **T-SQL** queries and ETL processes, reducing processing times by **25%**.
- Automated **15+ SSIS ETL workflows** using Python scripting.
- Developed **Power BI dashboards** using Azure Synapse and Azure Storage data with drill-down and drill-through reporting.
- Maintained **Informatica PowerCenter** mappings and workflows.
- Tuned dynamic SQL queries, reducing report generation times by up to **20%**.
- Managed Azure Data Lake access using **ACLs** and documented data security protocols.

## Technology Stack

**Azure:** Azure Data Factory, Azure Synapse, Azure Storage, Azure Data Lake  
**ETL:** SSIS, Informatica PowerCenter, Python  
**Database:** SQL Server, T-SQL, Dynamic SQL  
**BI:** Power BI  
**Security:** Azure Data Lake ACLs
