# SQL & Data Warehouse Engineering

## Overview

Portfolio case study based on Shirisha Gaddam's SQL Developer experience at Arch Insurance (May 2022 – Jun 2023).

The resume documents database development, batch automation, data warehousing, reporting support and data validation.

## What I Worked On

- Developed **30+ complex PL/SQL scripts** using Oracle for automated data extraction and transformation.
- Reduced manual processing errors by **25%**.
- Designed **MySQL DML procedures** and parameterized reporting solutions.
- Automated **15+ batch jobs** using SQL Server Agent and batch scripting.
- Reduced data pipeline downtime by **20%**.
- Implemented **star and snowflake schema** designs for data warehousing.
- Supported **MOLAP and ROLAP** reporting and query performance optimization.
- Validated data pipeline designs and tested workflows, contributing to a **30% reduction in data inconsistencies**.

## Technology Stack

**Database:** Oracle, MySQL, SQL Server  
**Languages:** PL/SQL, SQL, DML  
**Automation:** SQL Server Agent, Batch Scripting  
**Warehousing:** Star Schema, Snowflake Schema, MOLAP, ROLAP  
**Validation:** Data pipeline testing and workflow validation
