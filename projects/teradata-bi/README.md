# Teradata & Business Intelligence Engineering

## Overview

Portfolio case study based on Shirisha Gaddam's Data Engineer experience at Moback (Oct 2020 – Mar 2022).

The resume documents high-volume Teradata ingestion, enterprise reporting and ETL performance tuning.

## What I Worked On

- Executed **Teradata FastLoad** processes to ingest **10M+ records daily**.
- Optimized load times by **20%** in high-volume transactional platforms.
- Developed **SSRS and SSAS reports** with drill-down, matrix and crosstab reporting.
- Improved report clarity and reduced stakeholder queries by **30%**.
- Performed ETL performance tuning using **SQL Profiler and indexing**.
- Reduced pipeline runtime by **25%** and improved data pipeline stability.

## Technology Stack

**Database:** Teradata  
**Loading:** FastLoad  
**BI:** SSRS, SSAS  
**Performance:** SQL Profiler, Indexing, ETL Performance Tuning
